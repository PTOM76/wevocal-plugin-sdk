# 独自UI
FXプラグインは、標準のつまみ UI の代わりに独自のHTML画面を表示できる。

## 設定

`manifest.json` の `ui` に HTMLファイルを指定する。

```json
{
  "ui": "ui.html"
}
```

上記は設定例。実際のファイルパスはプラグインの構成に合わせる。

`ui` を省略した場合は、`params` の定義から標準 UI が生成される。

## 実行環境

独自UI は iframe の sandbox 内で動作する。許可されるのはスクリプトの実行のみで、アプリ内部のオブジェクトには直接アクセスできない。

ホストとの通信には `postMessage` を使う。

## メッセージのやり取り

### UI からホストへ

| メッセージ | 内容 |
| --- | --- |
| `{ wevocal: 'ready' }` | メッセージを受け取る準備ができたことを通知する |
| `{ wevocal: 'set', id, value }` | 指定したパラメータの値を変更する |

UI は初期化処理を終え、メッセージを受け取れる状態になったら `ready` を送信する。

パラメータを変更するときは、変更対象の `id` と新しい `value` を送信する。

### ホストから UI へ

| メッセージ | 内容 |
| --- | --- |
| `{ wevocal: 'init', params, values, texts }` | 初期化時にパラメータ、現在の値、翻訳テキストなどを渡す |
| `{ wevocal: 'values', values }` | パラメータの値が変わったときに通知する |

UI は `init` で受け取った情報を使って画面を初期化する。その後は `values` の通知に合わせて表示を更新する。

## 注意点

独自UI からアプリ内部の機能を直接呼び出すことはできない。パラメータの変更や値の取得は、定義されたメッセージを通して行う。
